# Release v1.4.0

## Objective

Publish the current approved project changes as version `1.4.0` and produce a new GitHub Release with the Windows installer artifacts.

## Approved scope

- Align root, Electron, backend, frontend, and shared workspace versions to `1.4.0`.
- Include the current source, Prisma migration, seed helper, UI, Electron, and documentation changes in the release commit.
- Run the monorepo build before publishing.
- Push the `remote` branch and the `v1.4.0` tag.
- Let the existing `Windows Setup` GitHub Actions workflow build and publish the installer assets.
- Verify the workflow and published release artifacts.

## Non-goals

- Do not change the Dongil Server API contract beyond the already implemented changes.
- Do not add dependencies.
- Do not fix the previously reported React hook lint findings unless they block the approved build.
- Do not rewrite or move an already published release tag.

## Risks and mitigations

- Sensitive local files could be committed: inspect status and scan changed files before staging.
- Version metadata could remain inconsistent: update all workspace manifests and lockfile together.
- Local build could fail: do not commit, push, or tag until it succeeds.
- GitHub installer workflow could fail after tag publication: preserve the published tag, report the failure, and use the workflow repair path or a subsequent patch version as appropriate.

## Rollback

- Before push: keep all changes local and do not create a tag if the build fails.
- After branch push but before tag push: release is not published; fix with a follow-up commit if needed.
- After tag push: do not rewrite the public tag. Repair the workflow for the same commit when possible, otherwise publish a patch release.

## Definition of Done

- [ ] Version metadata is `1.4.0` across all workspaces and lockfile.
- [ ] Changed files are reviewed for accidental secrets and generated artifacts.
- [ ] Monorepo build completes successfully.
- [ ] Release commit is pushed to `origin/remote`.
- [ ] Tag `v1.4.0` is pushed.
- [ ] GitHub Release `v1.4.0` exists with the expected Windows installer assets.
