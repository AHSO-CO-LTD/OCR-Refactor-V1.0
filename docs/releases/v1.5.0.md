# AHSO OCR Metal Core Washing 1.5.0

Release date: 2026-10-12

## Features

- Remembered login is available to all active roles and restores a valid
  machine-bound session after application restart or Windows cold boot.
- Local authentication sessions can be revoked on logout, role changes,
  deactivation, deletion, and remembered-login replacement.
- Operator users can refresh, reconnect, and synchronize approved Dongil data
  without receiving configuration-edit privileges.
- Dongil server configuration is database-authoritative after one-time legacy
  import, and the local machine type remains fixed to `WASHING_MACHINE`.

## Fixes

- Corrected packaged frontend API routing to the local production backend on
  `127.0.0.1:3979`.
- Improved Windows cold-boot and in-app restart recovery for the local API and
  remembered login.
- Added CR/LF/BOM-aware runtime environment parsing and legacy ProgramData
  backup handling.
- Changed the default uninstall choice to remove the application while
  preserving database, configuration, logs, backups, and support data.

## Database

- Adds remembered-login, audit, Dongil configuration, and revocable
  authentication-session migrations. Existing production inspection and Dongil
  result data are preserved.

## Security

- Remembered login stores no password or durable access JWT. Electron protects
  the opaque local token with Windows `safeStorage`; PostgreSQL stores only its
  hash and machine/user binding.
- HTTP and camera WebSocket authorization validate active local session state.
- Protected license source and the read-only Device Tool are unchanged.

## Known Limitations

- Dependency-security upgrades and local-service network-binding hardening are
  deferred to a follow-up release to preserve the accepted RC2 behavior.
- Free-angle ROI display and the Device Tool crop contract are not yet fully
  equivalent; current Tool rotation remains limited to 90-degree increments.
- Detailed update rollback, downgrade recovery, and the complete session
  revoke/WebSocket acceptance matrix still require separate target-machine
  evidence.
